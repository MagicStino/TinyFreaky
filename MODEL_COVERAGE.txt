# Independent prototype coverage

The DSP in src/engine.c is still approximate independent code. Direct firmware reverse engineering is now permitted. Factory parameters are included separately; this does not establish original sound or complete preset behavior.

Indices 0–15 are Tinyfreaky stable UI indices, never firmware model IDs. Indices 16–21 identify unavailable documented models for import diagnostics and are omitted from the selectable UI.

The engine has four-note paraphony, shared topology-preserving state-variable LP/BP/HP filter, per-voice envelopes with shared decay/release control, glide, bend, velocity and pressure. Six LFO shapes support free and host-tempo synchronized rates. Cycling envelope has rise/fall, curvature and hold; Env is gated, Run is free, Loop restarts on note triggers. Curves and timings are independent.

The full 5x7 matrix supports bipolar amounts, fixed destinations and three assignments, including matrix amounts via a one-sample-delayed routing feedback. Unsupported assignment destinations Sample and Arp/Seq rate retain their automation values but remain inactive, with an explicit status message. Arpeggiator, sequencer, spice/dice, sample import and user wavetable import are not implemented. Factory data must not be silently imported for unsupported controls or engines.

State MFZ1 stores stable numeric parameter order, validates all fields and rejects user-table/sample/vocoder models. It contains patch controls only; live notes, random generator and transport state are not serialized. Eight original built-in sounds are supplied. Original factory patch translation remains a separate compatibility task, with sound equivalence unverified.

44.1 kHz engine only. Native device performance and acoustic fidelity require actual hardware validation.

External banks: create(data_dir) scans sorted .mfz text files once, preloading up to 504 valid patches plus eight built-ins. Optional first line MFZNAME:name, followed by the MFZ1 state line. Invalid or unsupported patches are omitted. bank_count reports available slots; preset selection acknowledges 0..511 for host automation. Selecting an absent slot retains the previous sound, stores the selected slot and explicitly reports unavailable. MIDI CC9 is intentionally ignored because the public model chapter order does not establish firmware enumeration. Other documented synthesis CCs are mapped; arp CC91/92 are unavailable.

The preset control is an integer selector rounded by the engine, with programs available through the native preset menu. Its 512-slot Q-Link behavior depends on the host wrapper handling continuous drags separately from wheel ticks. Unavailable slot selection is retained for host automation while the last playable patch continues sounding.

Factory browser: 448 distinct original entries embedded, 334 partial translations, 114 unavailable engines muted. Original banks and required asset containers are retained in assets/factory.
