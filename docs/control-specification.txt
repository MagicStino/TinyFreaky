TinyFreaky control implementation

Keep parameter and automation IDs stable. Wave, Timbre and Shape labels follow the selected engine. The 5 x 7 matrix contains bipolar routing amounts and three assignable destinations. MIDI input supports notes, pitch bend, pressure and assigned CC messages. Use distinct free/synchronized LFO and rhythm rates. Shared Decay/Release is one control. The implementation supports sixteen engines; six additional families remain unavailable.
