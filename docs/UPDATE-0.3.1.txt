Tinyfreaky 0.3.1 — signal-path clarity and engine identification

The shared low-pass cutoff used an uncalibrated exponential curve: 30 * 500^x Hz, giving 671 Hz halfway and 15 kHz fully open. Imported normalized patch settings often lost too much upper detail. The new response is 30 + 19970*x^3 Hz (2526 Hz halfway, 20 kHz fully open). Cutoff now displays Hz. This is a deliberate musical response revision, not a measured emulation of Arturia's analog filter. Saved parameter values and modulation depths are retained; older patches will sound brighter at the same cutoff value.

Oscillator -> velocity/envelope -> four-voice headroom -> shared selectable LP/BP/HP state-variable filter -> 20 Hz DC blocker -> linear output gain -> peak-only soft limiter -> master. Ordinary signals no longer pass through always-active tanh saturation. No shelf EQ or automatic per-preset normalization is added. The same corrected path serves all 16 implemented models; the original MIT oscillator cores stay unmodified.

Basic Waves now uses a band-limited pulse instead of a naive discontinuous square. SuperWave now has independently advancing side oscillators (up to ±35 cents), Wave morphs saw/pulse/triangle/sine, and Volume blends the two side voices. Previously its Detune control only shifted phase at the same frequency. These remain independent oscillator implementations, not exact MicroFreak models.

The main Force display shows ENGINE plus its number and name in larger white text, including changes to the rendered model caused by modulation. Desktop likewise emphasizes the selected engine. White: engine/preset selectors. Orange: oscillator macros and arp/play controls. Black with a light pointer: secondary mode selectors. Green: remaining continuous controls. The subtle background gradient is retained.

Validation: all 16 engines across three filter modes and four parameter extremes with four-note chords; finite filter state and bounded output; DC rejection; actual SuperWave phase separation; engine/state/factory/rhythm and Force host ABI tests; generated Force layouts; Linux VST3 validator and host smoke. assets/clarity-audit.json records the repeatable factory comparison: C4 velocity100, 0.5 seconds, arp/seq disabled, spectral energy above2kHz relative to total. Of 334 playable entries, 314 produced measurable sustained output and 162 gained at least0.001 high-frequency energy fraction. Transient/slow-attack or deliberately dark patches need musical listening; these statistics do not establish preset fidelity.

Six engine families remain unavailable, and original binary factory sequences/modulation tracks remain undecoded. Hardware sound/CPU and Windows/macOS of this revision are unverified. Save a copy of projects before comparing revisions: the intended cutoff and SuperWave changes alter their sound.
